# RoboMaster 装甲板识别与位置解算

本项目为 27 赛季算法组视觉侧第二周培训作业。

项目使用 C++17、OpenCV、OpenVINO、CMake 实现 RoboMaster 装甲板识别与位置解算。

完成两种装甲板识别方案：

1. 基于 OpenCV 的传统视觉识别
2. 基于 ONNX 神经网络的装甲板识别

两种方案最终统一得到装甲板四个角点，并利用相机内参和装甲板实际尺寸，通过 PnP 解算装甲板在相机坐标系中的三维位置。

---

# 1. 功能

项目当前实现：

- 视频读取
- 图片读取
- 相机参数 YAML 读取
- 红蓝灯条提取
- 灯条几何筛选
- 灯条配对
- 装甲板四角点提取
- MLP 数字分类
- ONNX 装甲板神经网络推理
- PnP 三维位置解算
- 视频结果绘制
- 真值图片坐标评测
- Δx、Δy、Δz 误差计算
- 三维位置误差计算
- CSV 评测结果导出
